# Custom cursor files

The app uses these `.cur` files for the cursor:

| File | When it's used |
|------|----------------|
| **normal.cur** | Default cursor (non-clickable areas) |
| **pointing.cur** | Over links, buttons, and other clickable elements |

**Size:** CSS cannot resize cursor images. To get “standard size, slightly bigger”:
- **Standard:** 32×32 px  
- **Slightly bigger:** 36×36 px or 40×40 px  

Export or resize your `.cur` files to one of these dimensions (e.g. in your cursor editor, or by creating 36×36 / 40×40 versions). Replace the files in this folder and refresh the app.

Hotspot (click point) is defined inside each `.cur` file.
