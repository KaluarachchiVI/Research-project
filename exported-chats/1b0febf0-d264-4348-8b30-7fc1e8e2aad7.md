## What the plugin does

The plugin adds **Figma MCP (Model Context Protocol)** support so the AI can work with Figma designs and your code together.

### 1. **Skills** (automatic when relevant)

The plugin provides three skills that the agent can use when you ask for these kinds of things:

| Skill | When it’s used |
|-------|-----------------|
| **implement-design** | You say things like “implement design”, “generate code from Figma”, “build this component”, or share Figma URLs. It turns Figma designs into code that matches the design. |
| **code-connect-components** | You say “code connect”, “connect this component to code”, “link component to code”, etc. It maps Figma components to your code components (Code Connect). |
| **create-design-system-rules** | You say “create design system rules”, “generate rules for my project”, “set up design rules”. It creates project-specific rules for Figma → code workflows. |

You can also run these via **slash commands** with `/` in the chat.

### 2. **Figma MCP server**

- **Server name:** `plugin-figma-figma` (referred to as “figma”).
- The server exposes tools the AI uses to talk to Figma (e.g. files, nodes, export).
- **Auth:** The server **requires authentication**.  
  To enable it, the AI (or you, via the MCP tool-calling UI) must call the **`mcp_auth`** tool for the server `plugin-figma-figma` with an empty arguments object `{}`. That starts the Figma login flow so the server can access your Figma account.

### 3. **Rules and hooks**

Any rules or hooks that came with the plugin are applied automatically in Cursor (e.g. how to treat Figma URLs or design tokens). You don’t need to run them manually.

## Quick start

1. **Authenticate:** Trigger auth for the Figma MCP server (e.g. by asking in chat to “authenticate Figma” or using the MCP tool for `mcp_auth` with server `plugin-figma-figma`). Complete the Figma login when prompted.
2. **Use it:** Ask in natural language, e.g. “Implement this Figma design” or “Connect this component to code,” or use the `/` commands for the skills above.
