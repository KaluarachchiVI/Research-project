Abstract

A study timer that adapts to how you actually work.

Traditional study timers enforce static work–break cycles and offer little adaptation to fluctuating cognitive demand, irregular study rhythms, or impulsive task switching. This project presents an integrated platform — the Adaptive Cognitive-Load Study Timer — that personalises study support through behavioural sensing, online learning, temporal profiling, and distraction-aware intervention.

The system comprises four cooperating services: a privacy-first Cognitive Load Estimator (14-dimensional features, 60-second window, 15-second hop) fused with micro-EMA via a scalar Kalman filter and RLS; an Adaptive Break Scheduler with a 16-arm work/break action space; a chronotype-aware time-of-day recommender using mabwiser LinUCB and an optional gradient-boosting weekly hybrid; and an Intent-Lock module using LogisticRegression and three-level friction. The architecture supports hybrid edge–cloud deployment with an OS-level capture agent and containerisable APIs.

System architecture

From signal to recommendation in four hops

The edge agent streams keyboard latency and pointer events to the CLE over HTTP. The web UI subscribes to CLE state via Server-Sent Events; the scheduler consumes estimates for contextual recommendations; the chronotype service may pull training data from the scheduler; and the Intent-Lock service scores exit intent.
